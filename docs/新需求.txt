## 核心变更对比

| 模块 | 当前实现 | 你的目标 |
|------|----------|----------|
| 画像 | 用户主动描述"我是XX专业"→LLM抽取 | AI自动分析对话记录+拍照解题+学习时长 → 画像 |
| 资源 | 用户说"生成文章"→单次生成 | 画像变化 → 自动触发资源生成 |
| 视频 | 无 | AI先生成提示词 → 外部视频AI根据提示词生成 |
| 习题 | 仅展示 | 用户可管理：错题本/收藏/删除 |
| 路径 | 纯文本验收标准 | 验收标准 → 可点击跳转对应学习资源 |

## 新架构数据流

```mermaid
flowchart TD
    A[AI对话] --> H[对话历史]
    B[拍照解题] --> H
    C[答题记录] --> H
    D[学习时长] --> H
    
    H --> P[ProfileAgent<br/>分析历史数据]
    P --> R[ResourceGenerator<br/>根据画像生成资源]
    R --> V[视频提示词 → 外部视频AI]
    R --> Q[习题 → 用户管理<br/>错题本/收藏/删除]
    R --> M[文章/代码/导图]
    
    P --> LP[PathPlanningAgent<br/>规划路径]
    LP --> CK[验收标准<br/>含资源跳转链接]
    
    E[EvaluationAgent] --> P
```

### 阶段 B：画像重构（预计 1.5 天）

#### B1 ProfileAgent 改造

```python
# 当前：只解析 user_message 这一个字段
# 改造：收集多数据源，统一分析

async def process(self, state):
    # 1. 从 DB 查询最近 7 天的对话历史
    chat_history = query_chat_history(user_id, days=7)
    
    # 2. 从 DB 查询答题记录统计
    quiz_stats = query_quiz_stats(user_id)
    
    # 3. 从 DB 查询学习时长分布
    session_stats = query_session_stats(user_id)
    
    # 4. 合并已有画像
    old_profile = query_profile(user_id)
    
    # 5. 构造综合 prompt，让 LLM 分析所有数据
    prompt = f"""
    对话记录：{chat_history}
    答题统计：{quiz_stats}  
    学习时长：{session_stats}
    当前画像：{old_profile}
    
    请综合分析，更新学生画像的 6 个维度...
    """
    
    # 6. LLM 输出 → 更新画像
```

#### B2 触发时机

| 触发条件 | 触发动作 |
|----------|----------|
| 每次对话结束 | 记录历史，异步触发画像微调 |
| 每完成 5 道习题 | 触发画像更新 |
| 每累计学习 30 分钟 | 触发画像重评估 |

### 阶段 C：资源生成重构（预计 2 天）

#### C1 画像驱动自动生成

```python
# services/resource_generator.py (新建)

async def generate_resources_for_profile(user_id):
    profile = get_profile(user_id)
    
    # 根据 profile.weak_points 生成针对性习题
    for weak in profile.weak_points:
        await ContentGenAgent().generate_quiz(weak)
    
    # 根据 profile.learning_goal 生成路径规划
    await PathPlanningAgent().plan(profile.learning_goal)
    
    # 根据 profile.knowledge_base 生成导图（对薄弱学科）
    for subject, score in profile.knowledge_base.items():
        if score < 0.4:
            await MindMapAgent().generate(subject)
```

#### C2 视频资源生成（两步法）

| 步骤 | 文件 | 说明 |

| 第1步 | `agents/content_gen_agent.py` | `_generate_video_prompt` → LLM 生成视频脚本+分镜+风格描述 |

### 阶段 D：路径资源关联（预计 0.5 天）

#### D1 路实验收标准跳转

```
当前 path.steps[i].checkpoint 是纯文本：
"学生应能独立写出带参数的Python装饰器"

改造后包含资源 ID：
{
  "checkpoint_text": "学生应能独立写出带参数的Python装饰器",
  "related_resource_ids": [12, 15],
  "related_resource_titles": ["装饰器专项练习", "装饰器代码案例"]
}
```

| 文件 | 改动 |
