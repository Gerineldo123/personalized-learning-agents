## 智能化教学视频搜索推荐方案

### 一、技术路线选择

采用 **AI 联网搜索**，而非网络爬虫。

| 维度 | AI 联网搜索（采用） | 网络爬虫（不采用） |
|---|---|---|
| 实现成本 | 低（LLM + `enable_web_search` 一行参数） | 高（反爬对抗、调度系统、存储维护） |
| 内容精准度 | ⭐⭐⭐⭐ 结合学生画像做语义搜索 | ⭐⭐ 关键词匹配 + 规则排序 |
| 时效性 | ⭐⭐⭐⭐ 实时全网搜索 | ⭐ 需持续增量爬取 |
| 法律风险 | ✅ 无 | ❌ 反爬/版权灰色地带 |
| 维护负担 | 零 | 高（站点改版、反爬策略升级） |
| 个性化能力 | ⭐⭐⭐⭐ 结合画像弱项、当前学习主题 | ⭐ 仅能做关键词检索 |

---

### 二、技术基础

当前系统主 LLM 为**讯飞星火 Spark API v3.5**，原生支持联网搜索：

```python
# core/llm_client.py 现有调用
resp = await client.chat.completions.create(
    model="generalv3.5",
    messages=messages,
    extra_body={"enable_web_search": True},  # ← 开启联网搜索
)
```

开启后，API 返回结构化的搜索结果，包含标题、URL、摘要。也可以在 prompt 中要求 LLM 自行组织搜索 query 并返回结构化 JSON。

### 四、实现方案

#### 4.1 新增 `backend/agents/video_agent.py`

```python
import json
from agents.base import BaseAgent, AgentState
from core.llm_client import chat_completion

VIDEO_PROMPT = """你是教学视频推荐助手。根据学生画像，联网搜索最相关的视频资源。

学生画像：
- 专业：{major}
- 年级：{grade}
- 水平等级：{level}
- 知识基础：{knowledge_base}
- 薄弱知识点：{weak_points}
- 学习目标：{learning_goal}

搜索要求：
1. 优先推荐中文教学视频（B站、慕课、网易公开课等）
2. 视频长度控制在 15-60 分钟
3. 针对学生的薄弱知识点，如有相关视频优先推荐
4. 每个视频说明推荐理由

返回 JSON 格式（只返回 JSON）：
{{
  "videos": [
    {{
      "title": "视频标题",
      "url": "视频链接",
      "source": "来源平台",
      "duration": "时长范围",
      "reason": "推荐理由（结合学生画像）"
    }}
  ],
  "search_summary": "搜索结果概括（一句话）"
}}

只返回 JSON，不要其他内容。"""


class VideoAgent(BaseAgent):
    name = "video"
    description = "根据学生画像联网搜索教学视频资源"

    async def process(self, state: AgentState) -> AgentState:
        profile = state.get("profile")
        profile_state = state.get("profile_analysis", {})

        prompt = VIDEO_PROMPT.format(
            major=getattr(profile, "major", "未知"),
            grade=getattr(profile, "grade", "未知"),
            level=profile_state.get("current_level", "中级"),
            knowledge_base=json.dumps(getattr(profile, "knowledge_base", {}), ensure_ascii=False),
            weak_points=json.dumps(getattr(profile, "weak_points", []), ensure_ascii=False),
            learning_goal=getattr(profile, "learning_goal", "未知"),
        )

        resp = await chat_completion(
            [
                {"role": "system", "content": prompt},
                {"role": "user", "content": state["user_message"]},
            ],
            temperature=0.5,
            extra_body={"enable_web_search": True},
        )

        raw = resp.choices[0].message.content.strip()
        if raw.startswith("```"):
            raw = raw.strip("`").strip()
            if raw.startswith("json"):
                raw = raw[4:].strip()

        try:
            result = json.loads(raw)
        except json.JSONDecodeError:
            result = {"videos": [], "search_summary": "搜索失败"}

        state["response"] = json.dumps({
            "agent": self.name,
            "action": "video_search",
            "videos": result.get("videos", []),
            "search_summary": result.get("search_summary", ""),
        }, ensure_ascii=False)

        return state
```

#### 4.2 新增 `backend/graph/nodes/video.py`

```python
from graph.state import AgentGraphState
from agents.video_agent import VideoAgent
from agents.base import AgentState

_video_agent = VideoAgent()


async def video_node(state: AgentGraphState) -> dict:
    agent_state = AgentState(
        user_id=state["user_id"],
        user_message=state["user_message"],
        profile=state.get("profile"),
        profile_analysis=state.get("profile_analysis", {}),
    )
    result = await _video_agent.process(agent_state)
    response = result.get("response", "")

    completed = list(state.get("completed_tasks") or [])
    completed.append({"agent": "video", "result_summary": "视频搜索完成"})

    return {
        "response": response,
        "agent_feedback": {"task_completed": True, "all_tasks_done": True},
        "messages": [{"role": "assistant", "content": response}],
        "completed_tasks": completed,
        "workflow_outputs": [
            {"stage": "video_search", "data": response}
        ],
    }
```

### 六、降级策略

如果联网搜索因 API 限制不可用（免费版讯飞星火可能不支持），提供两种降级方案：

**方案 A：伪搜索（LLM 自行推荐）**

不开启 `enable_web_search`，让 LLM 根据常识推荐已知优质视频资源（如 3Blue1Brown、StatQuest 等知名频道），标注"推荐搜索关键词"供用户自行检索。

**方案 B：对接 YouTube Data API v3**

```python
# 降级为 YouTube 搜索
YT_SEARCH_URL = "https://www.googleapis.com/youtube/v3/search"
params = {
    "part": "snippet",
    "q": search_query,         # 由 LLM 根据画像生成
    "type": "video",
    "maxResults": 5,
    "relevanceLanguage": "zh",
    "videoDuration": "medium",
    "key": YOUTUBE_API_KEY,
}
```

YouTube API 免费额度为 10,000 次/天，对教育场景足够。
