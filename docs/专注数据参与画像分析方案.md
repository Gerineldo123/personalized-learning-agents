## 专注数据参与画像分析方案

### 一、现状

当前"专注淀粉肠"模块的专注数据（淀粉肠累计数、每次专注的时长与完成状态）仅存储于浏览器 `localStorage`，与后端零交互。`ProfileAgent` 构建学习画像时，仅参考以下三类数据：

| 数据源 | 来源 |
|---|---|
| `old_profile` | `student_profiles` 表 |
| `chat_summary` | `conversations` + `chat_messages` 表 |
| `quiz_stats` | `quiz_records` 表（答题次数 + 平均正确率） |

专注行为数据（每日专注时长、完成率、中断模式）完全没有进入画像分析视野，造成了信息浪费。

---

### 二、目标

将专注数据接入画像分析链路，使系统能够：

1. 追踪学生的学习投入度（专注时长、频次、趋势）
2. 识别专注模式中的异常行为（频繁中断、时段偏好等），作为薄弱点辅助诊断
3. 在能力雷达图中新增"专注耐力"维度，丰富画像层次
4. 为学习路径规划提供时间管理维度的参考

---

### 三、数据链路

```
┌──────────────┐     POST /api/focus/session      ┌──────────────┐
│  PathView.vue │ ─────────────────────────────────>│  focus 路由   │
│  focus.ts     │     completeFocus() / unlockFocus() │              │
│  localStorage │                                    │  focus_sessions 表 │
└──────────────┘                                    └──────┬───────┘
                                                           │
                        PROFILE_PROMPT 引用               │
┌──────────────┐  <───────────────────────────────────────┘
│ ProfileAgent │   读取 focus_sessions + student_profiles
└──────────────┘
```

- **前端**：每次专注会话结束（完成或中断），调用 `POST /api/focus/session` 上报。
- **后端**：新增 `focus_sessions` 表持久化，`ProfileAgent` 的 prompt 中增加专注数据维度，在画像构建/更新时一并分析。

### 四、数据库设计

#### 4.1 新增表 `focus_sessions`

```sql
CREATE TABLE focus_sessions (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id       VARCHAR NOT NULL,
    started_at    DATETIME NOT NULL,          -- 会话开始时间
    duration_min  INTEGER NOT NULL,           -- 计划/实际分钟数

CREATE INDEX idx_focus_user ON focus_sessions(user_id);
CREATE INDEX idx_focus_date  ON focus_sessions(started_at);
```

实现文件：`backend/api/routes/focus.py`

```python
from fastapi import APIRouter, Depends
from pydantic import BaseModel
from sqlalchemy.orm import Session
from api.deps import get_db
from models.focus import FocusSession

router = APIRouter(prefix="/api/focus", tags=["专注"])


class FocusSessionIn(BaseModel):
    started_at: str   # ISO-8601
    duration_min: int
    completed: bool = True


@router.post("/session", status_code=201)
def create_session(body: FocusSessionIn, user_id: str, db: Session = Depends(get_db)):
    session = FocusSession(
        user_id=user_id,
        started_at=body.started_at,
        duration_min=body.duration_min,
        completed=body.completed,
    )
    db.add(session)
    db.commit()
    db.refresh(session)
    return {"id": session.id}


@router.get("/stats")
def get_stats(user_id: str, db: Session = Depends(get_db)):
    sessions = (
        db.query(FocusSession)
        .filter(FocusSession.user_id == user_id)
        .order_by(FocusSession.started_at.desc())
        .all()
    )
    if not sessions:
        return {
            "total_sessions": 0, "completed_sessions": 0,
            "interrupt_rate": 0, "total_minutes": 0,
            "weekly_avg_min": 0, "peak_hours": [],
            "recent_sessions": [],
        }

    total = len(sessions)
    completed = sum(1 for s in sessions if s.completed)
    total_min = sum(s.duration_min for s in sessions)
    interrupt_rate = round((total - completed) / total, 2)

    # 周均：按最近4周计算
    from datetime import datetime, timedelta, timezone
    now = datetime.now(timezone.utc)
    four_weeks_ago = now - timedelta(weeks=4)
    recent_sessions = [s for s in sessions if s.started_at.replace(tzinfo=timezone.utc) >= four_weeks_ago]
    weeks = max(1, (now - four_weeks_ago).days / 7)
    weekly_avg = round(sum(s.duration_min for s in recent_sessions) / weeks)

    # 高效时段：统计完成会话中 start_at 的小时分布（取前三）
    from collections import Counter
    hour_counts = Counter(s.started_at.hour for s in sessions if s.completed)
    peak_hours = [h for h, _ in hour_counts.most_common(3)]

    return {
        "total_sessions": total,
        "completed_sessions": completed,
        "interrupt_rate": interrupt_rate,
        "total_minutes": total_min,
        "weekly_avg_min": weekly_avg,
        "peak_hours": peak_hours,
        "recent_sessions": [
            {
                "started_at": s.started_at.isoformat() if s.started_at else None,
                "duration_min": s.duration_min,
                "completed": s.completed,
            }
            for s in sessions[:20]
        ],
    }
```

在 `completeFocus()` 和 `unlockFocus()` 中增加上报逻辑：

```typescript
// stores/focus.ts 中的改动

import { reportFocusSession } from '../api/focus'

function completeFocus() {
  stopTimer()
  removeGlobalListeners()
  exitFullscreen()
  state.value = 'completed'
  starchSausages.value++
  localStorage.setItem('starch-sausages', String(starchSausages.value))
  const session = {
    date: new Date().toISOString(),
    minutes: focusTotal.value / 60,
    completed: true,
  }
  focusSessions.value.unshift(session)
  if (focusSessions.value.length > 50) focusSessions.value = focusSessions.value.slice(0, 50)
  localStorage.setItem('focus-sessions', JSON.stringify(focusSessions.value))

  // 上报到后端
  reportFocusSession({
    started_at: new Date(Date.now() - focusTotal.value * 1000).toISOString(),
    duration_min: Math.round(focusTotal.value / 60),
    completed: true,
  }).catch(() => {}) // 静默失败，不阻塞前端体验
}

function unlockFocus() {
  stopTimer()
  removeGlobalListeners()
  exitFullscreen()
  const minutes = Math.ceil((focusTotal.value - focusRemaining.value) / 60)
  if (minutes > 0) {
    const session = {
      date: new Date().toISOString(),
      minutes,
      completed: false,
    }
    focusSessions.value.unshift(session)
    if (focusSessions.value.length > 50) focusSessions.value = focusSessions.value.slice(0, 50)
    localStorage.setItem('focus-sessions', JSON.stringify(focusSessions.value))

    // 上报到后端
    reportFocusSession({
      started_at: new Date(Date.now() - (focusTotal.value - focusRemaining.value) * 1000).toISOString(),
      duration_min: minutes,
      completed: false,
    }).catch(() => {})
  }
  state.value = 'idle'
}
```

> **注意**：上报使用 `.catch(() => {})` 静默处理，即使网络异常也不影响前端计时器功能。`localStorage` 数据保留作为降级方案。

#### 7.3 新增 `_get_focus_stats()` 方法

```python
def _get_focus_stats(self, db, user_id: str) -> str:
    from models.focus import FocusSession

    sessions = (
        db.query(FocusSession)
        .filter(FocusSession.user_id == user_id)
        .order_by(FocusSession.started_at.desc())
        .all()
    )
    if not sessions:
        return "暂无专注记录"

    total = len(sessions)
    completed = sum(1 for s in sessions if s.completed)
    total_min = sum(s.duration_min for s in sessions)
    interrupt_rate = round((total - completed) / total * 100, 1)  # 百分比

    # 高效时段
    from collections import Counter
    hour_counts = Counter(s.started_at.hour for s in sessions if s.completed)
    peak_hours = sorted([h for h, _ in hour_counts.most_common(3)])

    return json.dumps({
        "总专注次数": total,
        "完成次数": completed,
        "中断次数": total - completed,
        "中断率": f"{interrupt_rate}%",
        "累计专注分钟": total_min,
        "高效时段(小时)": peak_hours,
    }, ensure_ascii=False)
```

### 十、注意事项

1. **上报时机**：在 `completeFocus()` 和 `unlockFocus()` 的末尾异步调用，不动阻塞计时器逻辑
2. **降级策略**：上报失败不影响前端功能，`localStorage` 仍作为可靠数据源
3. **隐私**：专注数据仅用于本系统画像分析，不对外传输
4. **扩展性**：`FocusSession` 表预留了 `created_at` 字段，未来可扩展按日/周/月的聚合分析
5. **与现有画像的兼容**：`_merge_profile()` 中所有新字段均使用 `if ... is not None` 判断，老画像无专注维度时不会报错，后续第 N 次画像更新时自动补充
