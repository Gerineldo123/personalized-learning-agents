## 大学生个性化学习系统 — 初次学习画像构建方案

### 一、画像构建流程概览

整体流程分为两个阶段：

1.  **问卷采集**：通过结构化的四步问卷，收集用户学历背景、学科归属、薄弱课程及详细痛点、学习目标。
2.  **画像生成**：大模型对问卷结果进行分析，生成能力雷达图与薄弱课程清单，构成初始学习画像。

---

### 二、第一阶段：画像问卷设计

#### 第一步：学历背景

**目标**：确定学习阶段，为课程推荐划定基础范围。

**题目1：你目前的学历层次与年级是？**（必选，联动选择）

-   **专科生**：大一 / 大二 / 大三
-   **本科生**：大一 / 大二 / 大三 / 大四 / 大五（适用建筑、医学等长学制）
-   **硕士研究生**：研一 / 研二 / 研三
-   **博士研究生**：博一 / 博二及以上

---

#### 第二步：学科归属

**目标**：划定专业领域，避免课程推荐过于宽泛，同时兼顾交叉学科。

**题目2：你的主修学科门类是？**（必选，单选）

-   哲学 / 经济学 / 法学 / 教育学 / 文学 / 历史学 / 理学 / 工学 / 农学 / 医学 / 军事学 / 管理学 / 艺术学 / 交叉学科

**题目3：你的课程还大量涉及其他领域吗？**（非必选，多选，最多2项）

-   选项同上14个门类
-   **说明**：为解决“生物信息学”“数字媒体艺术”等交叉专业学生画像失真的问题而设置。

---

#### 第三步：薄弱课程与痛点定位

**目标**：将模糊的“学不好”转化为结构化的具体痛点，是大模型画像生成的核心输入。

**环节A：快速定位课程**

-   系统根据第一步和第二步的选择，智能推送 **5~10 门种子课程**标签。例如：
    -   工学 + 大一：高等数学、线性代数、大学物理、C程序设计、Python程序设计
    -   文学 + 大一：现代汉语、中国文学史、基础写作、大学英语
    -   医学 + 大三：药理学、病理生理学、诊断学、内科学
-   种子课程下方提供 **“搜索其他课程”输入框**，学生可自行添加未被覆盖的课程。

**环节B：结构化描述薄弱点**（用户选择某门课后弹出）

> **请具体描述你在这门课上的薄弱点：**
>
> 1.  **薄弱知识点**：哪一章、哪个概念或题型最让你头疼？
>     *   示例：多元函数微分、指针与内存管理、酸碱平衡紊乱
>
> 2.  **困难类型**：你主要卡在哪一步？（可多选）
>     *   □ 概念理解不透彻
>     *   □ 公式/理论记不住
>     *   □ 解题没思路，不知从何下手
>     *   □ 代码编写或实验操作困难
>     *   □ 知识太多太杂，抓不住重点
>
> 3.  **影响范围**：这个问题对你造成了什么影响？（可多选）
>     *   □ 担心挂科或补考
>     *   □ 后续课程听不懂
>     *   □ 考研/保研复习受阻
>     *   □ 单纯想学懂，没有具体考试压力

---

#### 第四步：学习目标

**目标**：明确动力来源，决定后续推荐内容的深度与形式。

**题目4：你学习这门课最主要的目标是什么？**（每门课程可分别选择，单选）

-   A. 搞定即将到来的期末考试或补考（短期应试）
-   B. 为考研/保研打好基础（长期应试）
-   C. 完成一个项目、实验或大作业（项目驱动）
-   D. 真正理解知识，为后续课程铺路（扎实基础）

> 建议该问题在用户添加每门薄弱课时均出现一次，因为不同课程目标可能不同。

---

### 三、第二阶段：画像生成与雷达图设计

问卷完成后，系统调用大模型对采集的结构化数据进行分析，生成初始学习画像，由**能力雷达图**和**薄弱课程卡片**两部分组成。

#### 1. 能力雷达图（总览画像）

采用**抽象通用能力维度**，而非按课程划分，确保跨专业可比性。每个维度满分10分，分数越低表示该能力越薄弱。

| 维度 | 定义 | 对应的典型问卷特征（低分示例） |
|------|------|-------------------------------|
| **知识记忆** | 对基本概念、公式、事实的保持与再现能力。 | “公式记不住”“历史事件年份总搞混” |
| **逻辑推理** | 理解复杂概念、推导定理、分析问题结构的能力。 | “定理推导没思路”“代码逻辑理不顺” |
| **应用实践** | 将知识转化为解题、编程、实验操作或解决实际问题的能力。 | “会背公式但不会做题”“实验操作总失误” |
| **信息整合** | 从繁杂信息中梳理框架、抓住重点、建立知识体系的能力。 | “知识太杂抓不住重点”“不会做文献综述” |
| **应试能力** | 在考试场景下的策略、心态和时间管理水平。 | “担心挂科”“一考试就紧张、做不完题” |

**大模型打分依据**：
-   分析所有课程下的“困难类型”和“影响范围”分布。
-   若某学生在多门课中均提到“公式记不住”“知识点遗忘”，则“知识记忆”维度分数会被打低。
-   若反复出现“解题没思路”，则“逻辑推理”与“应用实践”分数可能双双降低。
-   “影响范围”中涉及考试担忧的条目越多，“应试能力”维度分数越低。

#### 2. 薄弱课程卡片（下钻详情）

能力雷达图下方，列出用户所选的每一门薄弱课程卡片。点击单张卡片，进入该课程的详细视图，包含：

-   **该课程专属能力分布**：复用以上5个能力维度，但仅基于该门课的问卷回答进行评分。例如，某学生在《高等数学》中只表达了“记不住公式”，则该课雷达图可能仅“知识记忆”偏低；而《C语言》中写了“代码写不出”，则“应用实践”维度明显偏低。
-   **薄弱知识点摘要**：直接呈现用户输入的薄弱知识点。
-   **推荐学习策略标签**：大模型根据该课的目标（如“短期应试”）和薄弱点类型，自动生成策略标签，如“真题强化”“概念精讲”“项目驱动实战”等。

---

### 四、用户界面呈现建议

**学习画像总览页**布局：

1.  **顶部**：大五维能力雷达图（蜘蛛网图），直观展示学习者整体能力轮廓。
2.  **中部**：能力维度简要解读卡片，用一句自然语言说明（例如：“你的知识记忆能力较强，但在应用实践和信息整合方面需要重点关注”）。
3.  **底部**：薄弱课程卡片列表，每张卡片显示课程名称、简要痛点标签（如“记不住公式”“解题没思路”），支持点击进入课程详情页。

**课程详情页**布局：

1.  **左侧/上方**：该课程专属的5维能力迷你雷达图。
2.  **右侧/下方**：系统生成的针对性学习建议，如“建议从[具体章节]的[基本题型]入手，每天进行3道真题拆解训练”。
