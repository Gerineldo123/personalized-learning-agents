# 栈与队列：受限线性结构及其典型应用

> 本文为项目团队原创课程资料，对应知识点“栈与队列”。

## 学习目标

理解栈的后进先出和队列的先进先出约束；掌握顺序栈、链栈、循环队列和链队列；能使用栈解决递归、括号匹配和表达式求值问题，使用队列解决调度、缓冲和广度优先搜索问题。

## 栈

栈只允许在栈顶插入和删除。入栈、出栈和读取栈顶在正常实现中均为 $O(1)$。顺序栈通常使用数组和栈顶下标，链栈使用链表头部作为栈顶。函数调用栈保存返回地址、参数和局部变量，因此递归深度过大可能导致栈溢出。

括号匹配时，遇到左括号就入栈，遇到右括号就检查栈顶是否为对应左括号。若不匹配、提前空栈或扫描结束后栈非空，表达式都不合法。表达式求值可使用操作数栈和运算符栈，也可先转换为后缀表达式再计算。

## 队列与循环队列

队列在队尾插入、队头删除。顺序队列若每次出队都移动元素会造成不必要的 $O(n)$ 开销，因此常使用循环数组。设数组容量为 `capacity`，队头为 `front`，队尾下一空位为 `rear`，下一个位置可写为 `(index + 1) % capacity`。

为了区分空队列和满队列，可以牺牲一个存储单元：`front == rear` 表示空，`(rear + 1) % capacity == front` 表示满。也可以额外记录元素数量，此时满队列条件为 `size == capacity`。两种方案都正确，但实现必须始终一致。

### Python 代码案例：括号匹配

```python
def brackets_are_valid(text):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for character in text:
        if character in pairs.values():
            stack.append(character)
        elif character in pairs:
            if not stack or stack.pop() != pairs[character]:
                return False
    return not stack
```

每个字符最多入栈、出栈一次，时间复杂度为 $O(n)$，最坏额外空间为 $O(n)$。提前遇到不匹配右括号时可以立即返回。

## 应用场景

深度优先搜索可以显式使用栈，广度优先搜索使用队列保存待访问节点。消息系统通过队列解耦生产者和消费者；操作系统调度使用不同优先级队列；浏览器前进后退常用两个栈描述状态迁移。

## 例题：层序遍历

二叉树层序遍历先将根节点入队。每次取出队头节点并访问，再将其非空左右孩子依次入队。每个节点入队和出队各一次，因此时间复杂度为 $O(n)$；队列最大长度与树的最大宽度有关。

## 常见错误

1. 循环队列取模时使用错误容量。
2. 入队前没有检查满队列，导致覆盖未读取数据。
3. 把队尾指针定义为“最后元素位置”，代码却按“下一空位”处理。
4. 用递归实现深度优先搜索却忽略极深图可能造成调用栈溢出。

## 练习与答案

**练习 1：** 容量为 8、牺牲一个单元的循环队列最多保存多少个元素？

**答案：** 最多保存 7 个元素，剩余一个位置用于区分空和满。

**练习 2：** 为什么队列适合广度优先搜索？

**答案：** 先进先出保证先发现的节点先扩展，因此节点按照距离起点的层次被处理。在无权图中，第一次到达节点时得到的路径边数最少。

## 本章小结

栈和队列的核心不是容器外形，而是操作受限形成的处理顺序。选择实现时应关注容量是否固定、是否需要动态扩展、并发访问和边界状态表达。
