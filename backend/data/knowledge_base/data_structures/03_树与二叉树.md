# 树与二叉树：层次结构、遍历与编码

> 本文为项目团队原创课程资料，对应知识点“树与二叉树”。

## 学习目标

理解树的节点、边、度、层次、高度和子树；掌握二叉树性质、遍历方法、二叉搜索树和哈夫曼树；能够分析递归遍历的时间与空间复杂度，并根据遍历序列恢复二叉树。

## 树与二叉树

树是一种无环的层次结构。除根节点外，每个节点只有一个父节点。含 $n$ 个节点的非空树恰有 $n-1$ 条边。二叉树要求每个节点最多有两个孩子，并区分左孩子和右孩子。满二叉树每层节点都达到最大数量；完全二叉树只允许最后一层不满，且节点从左到右连续排列，因此适合使用数组存储。

若完全二叉树按从 0 开始的下标存储，节点 `i` 的左孩子为 `2*i+1`，右孩子为 `2*i+2`，父节点为 `(i-1)//2`。堆正是利用这种映射在数组中维护完全二叉树。

## 遍历

前序遍历顺序为根、左、右；中序为左、根、右；后序为左、右、根；层序按层访问。递归写法直接对应定义，非递归写法通常借助栈。中序遍历二叉搜索树会得到非递减序列，这是检验结构和输出有序数据的重要性质。

遍历每个节点一次，时间复杂度为 $O(n)$。递归额外空间取决于树高 $h$，平衡树为 $O(\log n)$，退化链为 $O(n)$。分析时不能把所有二叉树默认成平衡树。

### Python 代码案例：非递归中序遍历

```python
def inorder(root):
    result = []
    stack = []
    current = root
    while current is not None or stack:
        while current is not None:
            stack.append(current)
            current = current.left
        current = stack.pop()
        result.append(current.value)
        current = current.right
    return result
```

显式栈保存尚未访问的祖先节点。每个节点入栈和出栈各一次，时间复杂度为 $O(n)$，额外空间上界由树高决定。

## 二叉搜索树

二叉搜索树要求左子树键值小于当前节点，右子树键值大于当前节点，重复键策略需由实现约定。查找、插入和删除的代价与树高相关。随机数据下平均可接近 $O(\log n)$，有序插入可能退化为链表并达到 $O(n)$。AVL 树、红黑树等平衡结构用于限制高度。

## 哈夫曼树

给定若干权值，反复选择权值最小的两棵树合并，可构造带权路径长度最小的哈夫曼树。若将字符频率作为权值，从根到叶路径上的左右分支编码可形成前缀码，没有任何编码是另一个编码的前缀，因此能够无歧义解码。

## 例题：由遍历序列恢复二叉树

已知前序序列和中序序列且节点值互不相同。前序第一个元素是根，在中序中找到根后，中序左侧属于左子树，右侧属于右子树；再根据左子树节点数量切分前序序列并递归处理。若节点值重复，则仅凭两种序列通常不能唯一确定结构。

## 常见错误

1. 混淆节点深度和树高度。
2. 删除二叉搜索树中有两个孩子的节点时破坏有序性。
3. 认为前序和后序总能唯一恢复二叉树。
4. 递归函数没有处理空节点或没有正确返回新子树根。

## 练习与答案

**练习 1：** 含 100 个节点的非空树有多少条边？

**答案：** 99 条。除根外每个节点对应一条连接父节点的边。

**练习 2：** 为什么哈夫曼编码需要字符频率？

**答案：** 高频字符应分配更短编码，低频字符可以使用较长编码，从而最小化频率加权后的总编码长度。

## 本章小结

树把数据组织成层次关系。遍历提供统一访问框架，搜索树支持动态有序查找，哈夫曼树体现了贪心构造。所有复杂度结论都应明确树高这一关键条件。
