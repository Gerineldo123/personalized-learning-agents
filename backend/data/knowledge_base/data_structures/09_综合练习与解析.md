# 数据结构综合练习、诊断方法与解析

> 本文为项目团队原创练习材料，覆盖数据结构课程全部核心知识点。

## 使用方法

练习不是为了记住固定答案，而是检验学生能否识别算法前提、维护结构不变量并分析边界。建议先独立写出过程，再对照解析定位错误属于概念混淆、边界遗漏、复杂度误判还是实现失误。

## 线性表与栈队列

**题 1：** 长度为 $n$ 的顺序表删除下标 0 元素，最坏需要移动多少个元素？

**解析：** 后续 $n-1$ 个元素都要前移，时间复杂度为 $O(n)$。

**题 2：** 单链表只有头指针，删除最后一个节点为什么不是 $O(1)$？

**解析：** 需要找到倒数第二个节点才能修改其 `next`，从头遍历为 $O(n)$。若维护尾指针也只能快速定位最后节点，仍无法直接找到其前驱，除非改用双链表。

**题 3：** 循环队列 `front == rear` 同时表示空和满会有什么问题？

**解析：** 状态无法区分。应牺牲一个位置、记录元素数量或使用额外标志位。

## 树与图

**题 4：** 二叉搜索树按升序插入 1 到 100，查找复杂度如何变化？

**解析：** 树退化为只有右孩子的链，高度为 100，最坏查找为 $O(n)$。平衡搜索树通过旋转等机制控制高度。

**题 5：** 已知前序和后序遍历能否唯一恢复普通二叉树？

**解析：** 通常不能。例如只有一个孩子的节点无法仅凭前后序判断孩子在左还是右。增加中序且节点唯一时通常可以恢复。

**题 6：** 带负权边的图能否直接使用 Dijkstra？

**解析：** 不能保证正确。Dijkstra 确定当前最短节点后不再回退，负权边可能在之后产生更短路径，破坏贪心前提。

## 查找、排序与哈希

**题 7：** 有序单链表是否适合二分查找？

**解析：** 中点定位需要线性移动，反复定位会抵消折半优势。顺序访问链表通常直接线性查找更合适。

**题 8：** 快速排序为什么可能达到 $O(n^2)$？

**解析：** 若每次分区极不平衡，只减少一个元素，则递归工作量为 $n+(n-1)+\cdots+1$。随机枢轴和三向切分可降低常见退化概率。

**题 9：** 开放定址哈希表删除元素时为什么使用墓碑？

**解析：** 直接置空会让查找误以为探测链结束，使后方冲突元素不可达。墓碑表示该位置可插入，但查找仍需继续。

## 综合设计题

**题 10：** 设计一个支持按学号查询、按成绩排名、撤销最近修改的学生管理系统。

**解析框架：** 使用哈希表按学号定位记录；排名可以使用数组和稳定排序，若持续动态排名可考虑平衡树或堆；撤销操作使用栈保存命令及修改前状态。回答应进一步说明数据同步、重复学号和撤销失败处理。

**题 11：** 某社交系统需要判断两人是否连通、寻找最短关注链并推荐共同好友，应使用哪些结构？

**解析框架：** 用图表示用户和关系；连通与最短无权路径可用 BFS；共同好友可对邻接集合求交，邻居使用哈希集合可提高成员判断效率。大规模系统还要考虑分区和近似算法。

## 错误诊断表

| 错误现象 | 可能原因 | 检查方法 |
| --- | --- | --- |
| 链表后半段丢失 | 指针更新顺序错误 | 在每次修改前保存原后继 |
| 二分查找死循环 | 区间定义和更新规则混用 | 写出循环不变量并检查边界是否缩小 |
| 图遍历重复节点 | 标记访问时机过晚 | 入栈或入队时立即标记 |
| 排序结果正确但不稳定 | 相等元素交换或合并顺序错误 | 给相等键附加原始编号验证 |
| 哈希表偶发查找失败 | 删除或扩容实现错误 | 构造冲突键并跟踪完整探测路径 |

## 代码诊断案例与答案

```python
def binary_search(values, target):
    left, right = 0, len(values) - 1
    while left <= right:
        middle = (left + right) // 2
        if values[middle] == target:
            return middle
        if values[middle] < target:
            left = middle + 1
        else:
            right = middle - 1
    return -1
```

**诊断问题：** 这段代码成立的前提是什么，循环为什么能够终止？

**答案：** 输入序列必须按同一比较规则有序；每轮都排除中点并令左边界增加或右边界减少，因此搜索区间严格缩小，最终找到目标或变为空区间。若把更新写成 `left = middle`，在相邻边界场景中可能无法收缩并导致死循环。

## 复习建议

先用小规模数据手工推演，再写代码并加入断言验证结构不变量。掌握度应由带知识点标签的题目提交结果更新，阅读完成或自我感觉不能替代测验证据。对错题应记录错误步骤，而不只记录最终答案。
