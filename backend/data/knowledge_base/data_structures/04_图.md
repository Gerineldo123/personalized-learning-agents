# 图：关系建模、遍历与路径算法

> 本文为项目团队原创课程资料，对应知识点“图”。

## 学习目标

理解有向图、无向图、权、路径、连通和环；掌握邻接矩阵与邻接表；能实现深度优先和广度优先遍历；理解拓扑排序、最短路径和最小生成树的适用条件。

## 图的表示

图由顶点集合和边集合构成。邻接矩阵使用二维数组表示顶点对之间是否存在边，判断两点是否相邻为 $O(1)$，但空间为 $O(V^2)$，适合稠密图。邻接表为每个顶点保存邻居列表，空间为 $O(V+E)$，适合稀疏图，也是多数实际网络的常用表示。

有向图中边具有方向，顶点具有入度和出度；无向图中一条边会出现在两个顶点的邻接关系中。实现时若忘记双向加入，会把无向图错误地变成有向图。

## 图遍历

深度优先搜索沿一条路径尽可能深入，遇到已访问节点或无路可走时回退，可使用递归或显式栈。广度优先搜索按距离层次扩展，使用队列。两者都必须维护访问标记，否则含环图会无限重复。

采用邻接表时，DFS 和 BFS 时间复杂度均为 $O(V+E)$；采用邻接矩阵时需要扫描整行邻接关系，复杂度为 $O(V^2)$。遍历非连通图时，应从每个尚未访问的顶点重新启动一次搜索。

### Python 代码案例：邻接表广度优先搜索

```python
from collections import deque


def breadth_first_search(graph, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return order
```

节点在入队时立即标记，避免同一节点被多个前驱重复加入队列。若要遍历非连通图，应对每个尚未访问的顶点再次启动搜索。

## 路径与生成树

无权图的最短路径可用 BFS。边权非负时可使用 Dijkstra 算法；若存在负权边，Dijkstra 的贪心确定过程不再可靠，应考虑 Bellman-Ford 等方法。Floyd 算法使用动态规划计算任意两点最短路径，时间复杂度为 $O(V^3)$，适合顶点数量较小且需要全源结果的场景。

最小生成树连接无向连通图的全部顶点，边数为 $V-1`，且总权值最小。Prim 算法逐步扩展已选顶点集合，Kruskal 算法按边权从小到大选择不会形成环的边，并查集可高效判断连通性。

## 拓扑排序

有向无环图可以进行拓扑排序。Kahn 算法反复取出入度为零的顶点，并删除其出边。若最终输出顶点数少于图中顶点数，说明存在有向环。课程先修关系、构建任务依赖和流水线调度都可以建模为有向无环图。

## 例题：校园导航

将建筑物视为顶点、道路视为边、距离视为权。若所有距离非负，可从当前位置运行 Dijkstra 得到到各建筑的最短距离。若还要支持任意起终点频繁查询，且建筑数量较少，可预先使用 Floyd 计算全源最短路径。

## 常见错误

1. 遍历时入队后才迟迟标记访问，导致同一节点重复入队。
2. 对含负权边的图直接使用 Dijkstra。
3. 把最短路径树当成最小生成树。
4. 只从编号 0 的顶点遍历，遗漏非连通分量。

## 练习与答案

**练习 1：** 为什么无权图 BFS 第一次到达某节点时就是最短边数路径？

**答案：** 队列保证距离起点为 $d$ 的节点先于距离为 $d+1$ 的节点扩展，因此首次发现节点时，不可能存在边数更少但尚未处理的路径。

**练习 2：** 最小生成树能否用于有向图？

**答案：** 通常课程中的 Prim 和 Kruskal 针对无向连通图。有向图对应的是最小树形图问题，定义和算法不同。

## 本章小结

图算法必须先核对方向、权值、稠密程度、连通性和是否含环。很多错误不是算法代码写错，而是没有满足算法前提。
